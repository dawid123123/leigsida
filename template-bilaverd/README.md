# Bílavernd template (gotowy)

Oficjalny live-template Leigsíða — kopia strony auto-protect w trybie DEMO (bez danych klienta).

```bash
cd template-bilaverd
npm install
npm run dev
```

Otwiera się na [http://localhost:3000](http://localhost:3000).  
Leigsíða (`npm run dev` w katalogu głównym) pokazuje ten template w iframe na [http://localhost:3001](http://localhost:3001).

**DEMO zawsze włączone** (`isDemo = true`) — Logo + placeholdery zamiast marki klienta.
