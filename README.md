# Leigsíða

Vefsíða á áskrift — leigsida.is

## Dev

```bash
npm install
npm run dev
```

Leigsíða: [http://localhost:3001](http://localhost:3001)

### Bílavernd template (gotowy)

```bash
cd template-bilaverd && npm install && npm run dev
```

Template DEMO: [http://localhost:3000](http://localhost:3000) — pokazywany w live preview na stronie głównej.
